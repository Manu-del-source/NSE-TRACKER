# NSE Tracker

NSE Tracker is an investor-intelligence dashboard for the Nairobi Securities Exchange.

## Product principles

- Separate verified ownership disclosures from market-data-derived estimates.
- Label sample values as illustrative; never present demo figures as live NSE data.
- Record source, publication date, and confidence for ownership events.
- Start with end-of-day market data; streaming data can be added after licensing and provider selection.

## Frontend

The frontend is built with Next.js, React, TypeScript, and Tailwind CSS. The first milestone is a responsive dashboard shell with illustrative data clearly identified.

## Status

Market-data integrations are not connected yet. No prices, volumes, or investor transactions shown in the initial UI should be interpreted as live or verified data.
